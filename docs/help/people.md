# People

Directory of everyone in the active employment set.

{{shot:people-directory}}

## Browse

- **Grid** or **List** layout (**callout 1**)
- Filter by **department**
- Incomplete filter (**callout 2**, from Dashboard / Data Health) focuses thin profiles
- Search (**callout 3**) by name, title, or department

## Profiles

Open a person via **Full profile** (**callout 4**) for title, department, country, manager, and avatar. From Data Health, **Fix in profile** deep-links here.

## Local profile fixes

**Save to Remote** writes department and manager through a server-side write token (`REMOTE_API_WRITE_TOKEN`). Job title and country are often blocked on **active** Global Payroll employments (Remote expects a contract amendment), so those fields fall back to a **local browser overlay** until Remote allows the change. Clearing local overlays restores the last Remote snapshot for those fields only.

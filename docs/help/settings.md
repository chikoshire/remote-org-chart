# Settings

Preferences and Remote connection for the demo app.

## Remote connect

The Connect wizard resumes org data using the **server-side** read-only Remote token. You never paste an API token in the browser. Disconnect pauses org fetch in this session. Connect turns it back on.

## Appearance

Toggle density preferences. Preferences persist on this device.

## Session

**Log out** lives under Settings → Session (not in the main header). Logout clears the demo session cookie and returns to the marketing landing.

## Data Health

Settings also hosts the Data Health surface for cycles, missing managers, and incomplete profiles.

# Settings

Preferences and Remote connection. Open the **gear** after Health and Help in the header.

{{shot:settings}}

## Remote connect

The Connect wizard (**callout 2**) resumes org data using the **server-side** Remote token. You never paste an API token in the browser. Disconnect pauses org fetch in this session. Connect turns it back on.

## Appearance

Toggle density preferences (**callout 3**). Preferences persist on this device.

## Session

**Log out** lives under Settings → Session (**callout 1 / 3**, not in the main header). Logout clears the session cookie and returns to the marketing landing.

Data Health is not under Settings. Open it from the **Health** control in the header.

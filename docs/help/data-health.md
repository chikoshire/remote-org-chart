# Data Health

Trust view for reporting edges and thin profiles. Open it from the **Health** control in the header (between search and Help / Settings).

{{shot:data-health}}

## Issue types

- **Reporting cycles (callout 1):** looped manager chains
- **Manager missing (callout 1):** manager id set but person not in the active set
- **Incomplete profiles (callout 1):** missing title, department, and/or country

## Fix in profile

Each card (**callout 3**) links to the People profile where you can fill missing fields. **Save to Remote** persists department and manager when a write token is configured. Title and country may stay as local overlays on active employments.

## Refresh from Remote

Use **Refresh from Remote** (**callout 2**) beside the intro copy to force a new Remote sync. The Sync KPI shows the last successful pull. Refresh keeps prior data if the rebuild fails.

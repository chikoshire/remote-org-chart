# Dashboard

The Dashboard is the at-a-glance view of Acme’s organisation.

{{shot:dashboard-overview}}

## What you see

- **People (callout 1):** active employment headcount — opens People
- **Departments (callout 1):** how many teams appear — opens Org Chart with the Department menu expanded
- **Managers (callout 1):** people with direct reports
- **Completeness (callout 1):** share of profiles with title, department, and country — opens Data Health
- **Headcount by department / country (callouts 3–4):** visual breakdowns with deep links into Chart / Map
- **Attention:** shortcuts into Data Health or incomplete People filters

## Refresh from Remote

Next to the synced timestamp (**callout 2**), use **Refresh from Remote** to bypass the cache and rebuild the org snapshot. The timestamp means the last successful Remote pull. While refreshing, the previous dashboard data stays on screen. If refresh fails, you keep that snapshot and see an error note.

## Jumping elsewhere

KPI cards and attention rows navigate into Org Chart, People, or Data Health. The Departments card opens Org Chart with the Department filter menu already expanded so you can pick a team right away.
